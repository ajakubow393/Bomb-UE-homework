# Bomb UE Homework

Unreal Engine 5.8 homework project.

## Features
- Bomb placement using Enhanced Input
- Press B to place a bomb
- Bomb detonates after 3 seconds
- Bomb pickup system
- Limited bomb count
- Explosion visual effect
- Radial force / explosion knockback
